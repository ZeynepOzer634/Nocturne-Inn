# Nocturne-Inn  ||  [Watch Gameplay Trailer]( https://youtu.be/hbYSQQVmfVM )

A Vampire Tavern Managament Game with also room mechanic where npc's stay-inn, as well as drink crafting and serving.

[Watch Gameplay Trailer]( https://youtu.be/hbYSQQVmfVM )

## Development & Version Control

This project was developed using by 2 developers using Unreal Engine 5, with Diversion as the primary version control system.


Gameplay & Systems Development by me – Unreal Engine 5 Production Studio Project
- Developed drink crafting and serving mechanics including ingredient collection, recipe matching, carried drink spawning, and customer order validation.
- Built a reusable interaction system using Blueprint Interfaces for ingredients, mixing counters, trash objects, merchant NPCs, and customer service interactions.
- Implemented inventory and item-state systems, including ingredient storage, clearing logic, crafted drink destruction, and UI-based player notifications.
- Designed a merchant unlock system where special ingredients are purchased with in-game currency and dynamically become available for crafting.
- Integrated drink systems with NPC order logic, ensuring customers only request valid drinks based on available ingredients and progression state.
- Collaborated with team members responsible for NPC behavior and level design to connect gameplay systems with customer flow, economy, and tavern progression.
